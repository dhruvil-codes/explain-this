Modern chatbots can answer questions, summarize documents, and write drafts. Most of them are powered by a design called the transformer, introduced in a 2017 research paper, which reads a whole sentence at once instead of word by word.

First, the input text is split into small pieces called tokens. A token can be a whole word, part of a word, or a punctuation mark. Each token is converted into a list of numbers, called a vector, that captures something of its meaning. Because the model reads everything at the same time, it also adds a position signal to each vector so that the order of the tokens is preserved.

The core of the transformer is a step called self-attention. For every token, the model creates three small vectors: a query, a key, and a value. You can think of the query as a question each word asks, roughly "which other words matter for me?", the keys as labels the other words hold up, and the values as the meaning each word offers. The model compares each query against every key, turns the scores into weights that add up to one, and blends the values according to those weights. The result is a fresh vector for each word that mixes in context from the rest of the sentence, so "bank" in "river bank" ends up represented differently from "bank" in "savings bank".

This comparison is done several times in parallel with different learned settings, called attention heads, so one head might track grammar while another tracks who did what to whom. The blended vectors then pass through a small feed-forward network, applied to each position separately, which refines them further. Around each of these steps sits a shortcut called a residual connection, which adds a step's input back to its output so that training stays stable, plus a normalization step that keeps the numbers in a healthy range.

These blocks are stacked, often dozens deep. Early layers tend to handle local patterns such as word pairs, while deeper layers build richer meaning. In models that write text, the final layer turns the last vector into probabilities over the vocabulary and picks the next token, then repeats the whole process to keep writing.
